# Resolve

Resolve is a cross-platform recovery and digital wellbeing platform designed to help users overcome compulsive online behaviors through intelligent blocking, recovery tools, AI coaching, and progress analytics.

## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS v4
- shadcn/ui
- Electron
- Express
- SQLite
- Zustand
- Framer Motion

## Project Structure

```
apps/
  web/
  desktop/
  api/

packages/
  ui/
  shared/
  database/
  blocker/
  recovery/
  analytics/
  ai/
```
